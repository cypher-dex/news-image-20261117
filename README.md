The world's news of Tuesday 17 November 2026 as a 33-story front page with a numbered world map, regional columns and figures. The lead image is an original generated linocut-style **editorial illustration**, not a documentary photograph (`bridge-art.webp`); story icons and map are drawn in `poster.html`. Render `poster.html` to `entry.png` with headless Chrome at 1024x1024; `main.ts` checks the PNG against the gate's limits and writes it to the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
